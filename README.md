# Mori Notes

一个只给自己用的 Android 笔记应用。纯 Java + Material Design 3，无第三方服务，不联网，数据完全在本地。

## 功能
- **普通笔记**：Markdown 编辑 + 实时预览，顶部标题框可直接改标题（留空则自动取正文第一句作标题并回填），支持插图、导出 TXT（保留标记 / 纯文本）/ PNG。
- **思维笔记**：大纲视图与脑图视图一键切换，脑图可双指缩放、拖拽，自适应屏幕居中对齐，可导出 PNG。
- **回收站**：入口在主页顶栏菜单，删除的笔记先进回收站，保留 10 天后自动销毁，显示删除时间与剩余天数，可恢复或彻底删除。
- **笔记分享**：笔记（文档 / 思维导图）可渲染成图片通过系统分享面板发出；普通笔记编辑页顶栏「分享」弹窗另有「分享 Markdown 文本」（保留语法原文）与「分享纯文本」（去除 Markdown 标记）。
- **待办**：底部导航栏第二项，参考小米笔记待办交互。列表按「进行中 / 已完成」分组，左滑删除，勾选即完成，顶栏可一键清除已完成；点条目进编辑页，返回自动保存。待办数据独立存于 `todos.json`。
- **倒数日**：卡片式倒数日 / 纪念日列表，显示剩余天数；点击进入全屏时间轴；「⋮」菜单编辑或删除；长按卡片进入多选，长按右侧「⋮」拖拽排序；退出应用自动取消多选；卡片「⋮」菜单「编辑」上方可分享图片；编辑时可设相册背景图；详情页可分享图片；主页「⋮」可把全部倒数日保存为图片（`Download/mori_notes/`，多条时每条单独存一张）或分享卡片长图，多选态保存所选同样分开存为多张；顶栏「多选」支持批量分享与批量删除；卡片「⋮」菜单「编辑字体」（「编辑」下方）可选跟随系统默认、字体库字体或导入新字体，全屏详情页亦可导入本地字体（ttf / otf / ttc）；保存/分享的长图背景跟随该条倒数日的全屏自定义背景。每条倒数日可单独绑定字体（全屏页菜单「选择字体」），未绑定时使用手机系统默认字体；导入的字体按原文件名累积成字体库，互不覆盖；全屏详情页「⋮」菜单新增「导入自定义字体」，可从本地选择 `.ttf` / `.otf` / `.ttc` 字体文件；主页顶栏「⋮」新增「保存图片」与「分享图片」，把全部倒数日渲染成卡片长图；图片保存到 `Download/mori_notes/`，分享直接发出卡片长图而非截屏；每条倒数日可绑定自己的字体文件，全屏页菜单新增「选择字体」，；长按倒数日卡片直接进入多选并选中该条（多选态长按弹全选/保存/分享/删除），退出应用或切到后台时自动取消多选；排序改为长按卡片右侧「⋮」按钮拖拽。卡片「⋮」菜单在「编辑」上方新增「分享图片」，直接分享该条倒数日卡片长图。
- **页面切换**：底部导航栏为「主页 | 待办」两项，左右滑动与点击双向联动，跟手切换无跳变。
- **设置入口**：设置页为独立页面，入口在主页、待办与倒数日顶栏菜单。
- **存储位置可选**：内部存储，或用 SAF 选择任意目录（配置文件 `notebook.json`），便于自行备份与同步。
- **背景与外观**：多种背景样式，可选用本地图片；全局跟随系统深浅色（MD3 主题色）。
- **隐私笔记**：主界面长按菜单可「设为隐私笔记」，隐私笔记不出现在普通列表、搜索与回收站统计中，仅从主页面向下拉手势进入。
- **密码保护**：首次进入隐私笔记须设置 4 位以上数字密码，或改用手机锁屏密码验证；未设置密码无法进入。
- **重置密码**：设置页新增「隐私笔记」卡片，重置需通过旧密码验证，或验证手机锁屏密码后重新设置。
- **导出位置**：所有导出（纯文本 / Markdown / 图片）统一保存到 `Download/mori_notes`，不再弹出文件选择器。
- **更名**：软件显示名正式改为 Mori Notes。
- **导出图背景跟随全屏**：保存/分享的卡片长图背景改用该条倒数日全屏模式的自定义背景图（居中裁剪铺满），并叠加与全屏一致的黑色蒙版，文字转为白色；无背景图时回退浅灰底与白底卡片。
- **编辑字体**：倒数日卡片「⋮」菜单提供「编辑字体」（位于「编辑」下方），弹窗可选「跟随默认字体」、字体库已有字体，或「导入新字体…」，设置后仅作用于该条倒数日。
- **字体库**：导入的字体按原文件名存入 `files/fonts/`，可累积多款互不覆盖，
- **多选保存分开存图**：批量保存与「保存全部」不再拼成一张长图，每条倒数日单独存为一张 PNG，文件名形如 `倒数日_01_标题_时间戳.png`，标题非法字符自动替换。
- **笔记文本分享**：普通笔记编辑页顶栏「分享」改为弹窗，可选「分享图片」「分享 Markdown 文本」（保留语法原文，标题加 `# `）「分享纯文本」（去除 Markdown 标记，列表转 `· `、图片转 `[图片]`），分享前自动保存当前编辑内容。
- **笔记标题可直接改**：笔记编辑页顶部（工具栏下方）新增标题输入框，显示并可编辑当前标题；留空时仍按正文首行自动生成标题。
- **标题留空自动取首句**：笔记标题栏留空时，保存/退出笔记会把正文第一句（到句末标点为止，最多 40 字）填成标题并回写到标题框，不再是「无标题」。
## 环境

- compileSdk 34 / minSdk 24 / targetSdk 34，Java 17
- Gradle 8.9 + AGP 8.5，依赖 appcompat 1.7.0 / recyclerview 1.3.2 / material 1.12.0 / viewpager2 1.1.0-beta02 / fragment 1.5.4

见 [CHANGELOG.md](CHANGELOG.md)。
